# ロゴの管理

採用デザインはA案「影絵の狐」です。

写し絵は、和紙の幕に裏から絵を映す見世物です。

ロゴには、灯りの透ける和紙に映った藍の狐の影を描いています。

- 以前の「撮影の判子」から、0.1.0の前に差し替えました。
  - 理由: 無難で、UTSUSHIEらしさが弱かったためです。

## 元画像と配布用アイコン

- `Resources/utsushie.png`: 1024×1024の透過PNGです。
  - 用途: READMEと派生画像の共通の元画像です。
  - 板の寸法: KIKIGAKIと揃えた944×944pxです。
  - 余白: 上下左右に40pxを置きます。
  - 管理: 採用済みの「影絵の狐」の整え直し版を正本として保ちます。
    - 制約: 形の変更や再生成は行いません。
- `Resources/utsushie.icns`: 配布用アプリアイコンです。
  - 寸法: 次の各サイズの1倍・2倍画像を格納します。
    - 16ポイント
    - 32ポイント
    - 128ポイント
    - 256ポイント
    - 512ポイント
  - 管理: 生成済みのICNSをリポジトリへ含めます。

`./scripts/make-icon.sh`でPNGからICNSを再生成します。

- 通常のアプリビルドは生成済みのICNSを同梱します。
  - 効果: ビルド時に画像生成ツールを必要としません。
- アプリは`CFBundleIconFile`で`utsushie.icns`を参照します。
  - 詳細: [AppleのCFBundleIconFile](https://developer.apple.com/documentation/bundleresources/information-property-list/cfbundleiconfile)
- メニューバーの待機中アイコンも同じICNSを18ポイントで表示します。
  - 表示: テンプレート画像にせず、ロゴの色を保ちます。
  - 板の表示幅: 余白を含めた18ポイントに対し、約16.6ポイントです。
- 録画中は赤の札「■ 0:12」で経過時間を表示します。
  - 操作: クリックするとメニューを開かずに録画を止めます。
- 準備中・書き出し中は、その言葉だけを表示します。
- 画像を同梱しない`swift run`では、待機中も従来の`viewfinder`シンボルを使います。

## 制作

- Codexの内蔵`image_gen`で生成した4案から、タダシがA案「影絵の狐」を選びました。
- クロディーヌが元の生成画像に2か所だけ手を入れました。
  - 縁: 細い縁を少し明るい藍にしました。
  - 内側: 縁の内側に和紙色の細い帯を重ね、左下の影を縁の手前で切りました。
  - 目的: 暗いメニューバーでも角丸の輪郭を残すためです。
- 採用画像をバイト単位でそのまま`Resources/utsushie.png`へ複製しています。
- 案と制作手順はowlery Vaultの`shared/images/utsushie-logo-concepts-2/`にあります。
  - 詳細: `prompts.md`
